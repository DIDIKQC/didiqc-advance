Cara Restore (ringkas)

  1. Pilih backup berdasarkan tanggal pada tabel di atas (nama file memuat tanggal & jam WIB).
  2. Buka GitHub → Actions → "DIDIQC Restore Database" → Run workflow.
  3. Isi: backup_file (contoh 2026-10-21 atau latest), target (neon / staging / custom / insforge-production), scope (app = tabel aplikasi saja — direkomendasikan untuk Neon).
  4. Untuk target staging/custom, isi restore_target_url dengan connection string database tujuan (ambil dari Neon console / provider).
  5. Restore ke produksi InsForge wajib isi confirm = RESTORE-PRODUCTION — sistem otomatis membuat backup keselamatan dulu dan mencetak prosedur rollback di log.
  6. Pantau hasil di log workflow; laporan verifikasi juga tersimpan di R2 database_didiqc/status/restore-log/.

Dokumentasi lengkap: docs/BACKUP-RESTORE.md di repositori.
Catatan keamanan: seluruh kredensial (R2/InsForge/Neon) hanya ada di GitHub Secrets & Vercel Environment Variables — tidak pernah ada di halaman ini.
