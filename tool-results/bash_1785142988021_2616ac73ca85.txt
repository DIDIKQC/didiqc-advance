    fix: View As dashboard charts + enhance Validasi QC menu
    
    1. View As dashboard bug fix:
       - renderSigmaBidangChart/renderCVBiasBidangChart replaced parent innerHTML
         when data empty, permanently destroying the <canvas>. Any later call with
         non-empty data threw TypeError (G('canvas')=null), aborting loadDashboard
         success handler before CV-Bias chart, WG panel, Trend Detail, weekly/monthly.
       - Now: hide canvas + show sibling .chart-no-data div instead of replacing
         parent innerHTML; recreate canvas if missing; wrap each render call in
         try/catch so one failure doesn't block others.
       - Fixed clearPageContent key mismatch (chartSigmaBidang -> sigmaBidang).
       - Trigger: View As a user with 0 params -> empty data -> canvas removed ->
         switch back to superadmin -> TypeError -> 3 dashboard sections blank.
    
    2. Validasi QC menu enhancements:
       - Added filter bar: date range (valStart/valEnd), bidang, parameter, status
         dropdown (Pending/Valid/Semua), Cari + Reset buttons.
       - Default: last 24h (start=yesterday, end=today) + status=pending (only
         unvalidated shown by default; validated QC hidden until user picks Valid).
       - Backend getInputQC now supports filter.status ('valid'|'pending').
       - Edit action (openEditValidasiModal): edit catatan validasi via new
         updateValidasiNote backend (preserves validatedBy/Date audit trail).
       - Hapus action (delValidasi): clear validation via new unvalidateQC backend
         (keeps QC data, only clears validated/validatedBy/Date/catatan).
       - Modal reused for both validate + edit-note modes (mValMode hidden field,
         dynamic title + submit button label).
       - Added validasiCache global for edit-modal prefill.
